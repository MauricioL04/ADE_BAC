## Reglas de la bóveda

1. **Siempre actualizar** después de un cambio real (nuevo agente, nueva skill, nueva política). Si no está aquí, no existe.
2. **Enlazar con `[[wikilinks]]`**, no con rutas. Obsidian lo requiere para el grafo.
3. **No duplicar** reglas del repo: enlazar a `.cursor/rules/*.mdc` cuando aplique.
4. **No pegar secretos ni datos de producción** aquí (regla `security.mdc`).
5. Cualquier decisión arquitectónica importante que surja de la bóveda → ADR en `docs/framework/adr/`.
